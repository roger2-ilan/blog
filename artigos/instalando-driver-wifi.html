Instalando o driver RTL8192EU no Arch Linux

Aprenda a instalar o driver RTL8192EU via DKMS no Arch Linux.

O driver RTL8192EU é utilizado por diversos adaptadores Wi-Fi USB baseados no chipset Realtek RTL8192EU, como:

  • D-Link DWA-131 Rev E
  • TP-Link TL-WN821N V6
  • Rosewill RNX-N180UBE v2

Em algumas versões do kernel Linux, o driver padrão rtl8xxxu pode apresentar problemas de compatibilidade, desconexões ou até mesmo não reconhecer corretamente o adaptador.

Neste tutorial veremos como instalar o driver alternativo via DKMS no Arch Linux.

Requisitos

Antes de começar, instale os pacotes necessários: 

sudo pacman -S --needed git dkms base-devel linux-headers
